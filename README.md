# U2-ejercicio38
### Generadores de Gráficos Estadísticos

**Objetivo principal:** Desarrollar un sistema modular en Java que permita representar datos estadísticos mediante diferentes tipos de gráficos.

Se implementa una clase abstracta `GeneradorGrafico` y tres clases concretas (`GraficoBarras`, `GraficoCircular` y `GraficoLineal`), cada una con su propia lógica de representación visual mediante la consola.

El ejercicio aplica **abstracción, herencia, polimorfismo, sobrescritura de métodos y colecciones**, incorporando validaciones para evitar la generación de gráficos cuando no existen datos disponibles.
